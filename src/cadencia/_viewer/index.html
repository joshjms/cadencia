Load an osu!mania chart with Python

Run uv sync, then use the library in uv run python:

import cadencia

chart = cadencia.osumania.load_chart(
    url="https://osu.ppy.sh/beatmapsets/2043161#mania/4855704"
)
cadencia.osumania.visualize(port="8080")

First run uv run scripts/download_ranked_mania.py to download and preprocess 100 ranked four-key charts. load_chart(name=...) and load_chart(url=...) read existing local charts from data/osumania/charts/<id>/trace.json and raise an error when absent. Refresh after downloading another chart.
